# ENO JAPAN Curriculum Seed

This directory is the source-of-truth preparation area for content that will later be loaded into Supabase.

## Scope

Levels: N5, N4, N3, N2, N1.

Each level is built as a connected curriculum:
- Vocabulary (kotoba)
- Kanji
- Grammar (bunpo)
- Example sentences
- Reading
- Listening
- Practice questions
- Review/assessment metadata

## Data policy

1. Do not claim a fixed official JLPT vocabulary/kanji/grammar list; JLPT does not publish one.
2. Use official JLPT competency/test-section information as the assessment framework.
3. Use established Japanese-learning references for coverage, while writing original ENO JAPAN explanations, examples and exercises.
4. Deduplicate concepts across references rather than inflating counts.
5. Do not reproduce copyrighted textbook passages, exercises, answer keys, or audio scripts.
6. Every batch must be validated before being considered complete.

## Progression

N5 must reach a strong, usable foundation before N4 is expanded; then N3, N2 and N1.

## JLPT framework

The 2026 JLPT has five levels (N1-N5). Current test times are documented by the official JLPT site. N5: Vocabulary 20 min, Grammar/Reading 40 min, Listening 30 min; N4: 25/55/35; N3: 30/70/40; N2: 105/50; N1: 110/55.

This seed plan is intentionally separate from the live database so Supabase failures do not block preparation of the curriculum.
