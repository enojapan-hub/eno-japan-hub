# ENO JAPAN V1 — Learning Priority

The learning experience is the primary V1 product surface.

## Required learning flow
- Kanji, Kotoba, Bunpō, Dokkai, and Chōkai must be clickable and data-driven.
- Each learning item should behave like a flashcard: prompt → reveal → explanation → examples → practice → feedback → next/review.
- Use Indonesian for all UI labels and explanations unless Japanese terminology is intentionally part of the lesson.
- Kanji: readings, meaning, stroke count when available, audio/TTS, related vocabulary, example sentences, and practice question.
- Kotoba: reading, meaning, forms, usage notes, multiple example sentences, related Kanji, audio/TTS, and practice question.
- Bunpō: pattern, meaning, structure, usage conditions, common mistakes, multiple examples, contrast with similar patterns, and practice questions with explanations.
- Learning content must use real database rows, not fixed demo cards.
- Daily learning should vary and respect level/retention state.
- Retention/spaced repetition must feed review queues and progress.
- Profile must show readable account identity, level, learning progress, streak, mastered items, and review queue.
- Free/Premium: free learning remains useful; social-follow reward grants 14 days Premium once per platform; referrals/share points can grant Premium according to configured reward rules.
- JLPT countdown and official announcement area are part of V1.

## Quality gate
No new feature is considered complete if its primary buttons/routes do not work end-to-end. Prefer fixing existing learning flows over adding decorative pages.
